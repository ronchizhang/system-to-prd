# 重绘规范

目标：把系统页面画成**看起来就是那个系统**的静态 HTML。不是重新设计，是还原。

---

## 一、一条铁律

**只做组件级调整，不做整体版式重构。**

用户说的是"和系统长得一样"，不是"帮我做得更好看"。任何"顺手优化布局"的动作都会被否掉，
因为原型的作用是让评审时能对着真实形态讨论，不是展示设计能力。

实测教训：把三列栅格改成两列、把卡片合并、把字段顺序重排，都属于越界。

---

## 二、先从系统里把真实尺寸量出来

不要凭感觉定字号和间距，直接问浏览器：

```js
// 量一个输入框
(() => {
  const el = document.querySelector('input');
  const c = getComputedStyle(el);
  return {h: el.getBoundingClientRect().height, radius: c.borderRadius,
          bg: c.backgroundColor, border: c.borderColor, font: c.fontSize};
})()
```

把量到的值写进 CSS 变量，全站复用：

```css
:root{
  --ink:#1D2939;        /* 主要文字 */
  --text2:#5C6F84;      /* 次要文字 */
  --text3:#8C99AB;      /* 提示文字 */
  --line:#E3E8EF;       /* 边框 */
  --brand:#1677FF;      /* 主色 */
  --bg-input:#F5F7FA;   /* 输入框底色 */
}
```

## 三、常用组件基线（典型后台，实际以量到的为准）

| 组件 | 关键值 |
|:--|:--|
| 输入框 | 高 32、圆角 6、底色 `#F5F7FA`、边框 `#E3E8EF` |
| 表格表头 | 高 40、底色 `#FAFBFD`、字重 600、`white-space:nowrap` |
| 表格行 | 行高 44、下边框 `#F2F5F9` |
| 卡片 | 圆角 10、边框 1px `#EBEEF3`、内边距 20 |
| 主按钮 | 高 32、圆角 6、底色 `#1677FF`、白字 |
| 次要按钮 | 高 32、圆角 6、白底、边框 `#D9DFE8` |
| 标签（tag） | 高 22、圆角 4、字号 11、左右内边距 6 |
| 弹窗 | 圆角 10、头高 52、脚高 56、`box-shadow:0 8px 30px rgba(0,0,0,.18)` |
| 分组标题 | 字号 14、字重 600、左侧 3px 竖条强调 |

## 四、布局规范

### 表单三列

```css
.fg{display:grid;grid-template-columns:repeat(3,1fr);gap:16px 18px;}
.fg .full{grid-column:1 / -1;}   /* 末项整行 */
```
字段顺序按系统实际顺序，不要为了"整齐"重排。

### 卡片分组

一个业务分组一张卡片，卡片头 = 标题 + 可选说明。**不要把一个分组拆成多张卡**，
也不要合并两个分组。

### 两栏（主内容 + 侧栏）

```css
.dtl{display:grid;grid-template-columns:1fr 372px;gap:16px;align-items:start;}
```
注意：这个类**只能用在页面级布局**，绝不能套进卡片正文（见 `css-pitfalls.md` 坑 1）。

## 五、状态必须画出来

原型最容易漏的不是正常态，是异常态。以下都必须有：

- **禁用态**：灰底 + 灰字 + 不可点
- **必填标记**：红色星号，位置在 label 后
- **校验错误**：红框 + 下方红字说明
- **空状态**：无数据时的占位文案
- **只读态**：文字代替输入框（系统自动计算的值必须用只读行，不能画成下拉）

真实教训：某"到账方式"字段系统是自动推荐、不可选，但重绘时画成了下拉框，
直接把产品意图画反了 —— 导致客户以为可以自选通道，而这条恰恰是业务的硬约束。

---

## 六、不要引入外部依赖

产物是**单文件 HTML**，离线可开。因此：

- 不引 CSS 框架、不引图标库、不引字体 CDN
- 图标用内联 SVG 或 CSS 画
- 弹窗遮罩用 `position:absolute;inset:0`，不用第三方组件

---

## 七、重绘完成后的自查

1. 随机挑 3 个字段，和系统截图对着看：位置、字号、必填标记是否一致
2. 看有没有"系统里是只读、你画成了输入"这类语义错误
3. 看异常态有没有画（禁用/错误/空）
4. 看卡片是否等高、栅格是否对齐（见 `css-pitfalls.md`）
